Sobre mim

Trabalho na integração entre o desenvolvimento de sistemas e o design de interfaces. Sou estudante de Análise e Desenvolvimento de Sistemas e foco na criação de projetos que unem uma estrutura lógica estável a um visual funcional e bem resolvido.

Meu fluxo de trabalho começa no Figma, onde desenvolvo o UI e UX Design focado no usuário. Para a implementação técnica, utilizo React, JavaScript e Tailwind CSS, garantindo que o resultado final seja fiel ao planejamento original e responda com eficiência no navegador.

Além da construção da interface com HTML e CSS, aplico boas práticas de organização e versionamento com Git, e uso o NPM para gerenciar as dependências dos projetos. Meu objetivo é sempre o equilíbrio: garantir que a tecnologia por trás do projeto seja sólida e que a experiência de quem usa seja simples, clara e direta.

Atualmente estou expandindo meu conhecimento para o desenvolvimento fullstack, buscando entender também a lógica por trás das APIs e dos dados que alimentam as interfaces que construo.
